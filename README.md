# Awesome EMG [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of resources related to **electromyography (EMG)** — the study and application of electrical signals generated by muscle activity. This list covers methods, datasets, applications, and hardware relevant to surface EMG (sEMG), high-density EMG (HD-EMG), and neural input interfaces.

Contributions are welcome! Feel free to open a pull request.

## Methods

Algorithms, models, and frameworks for decoding EMG signals.

### Deep Learning & Neural Interfaces

- **[emg2pose](https://github.com/facebookresearch/emg2pose)** — A benchmark and baseline models (from Meta / Facebook Research) for hand pose estimation from surface EMG. Provides three baselines (tracking and regression variants of `vemg2pose`, plus a `neuropose` regression model), pre-trained checkpoints, and a PyTorch-based training pipeline. Presented at NeurIPS 2024.
- **A generic non-invasive neuromotor interface for human-computer interaction** — Nature 2025. [Paper](https://www.nature.com/articles/s41586-025-09255-w). Demonstrates a generic, cross-user sEMG-based neuromotor interface for gesture decoding and HCI, foundational to Meta's wristband approach.

### Open-Source EMG Tooling

- **[BioPatRec](https://github.com/biopatrec/biopatrec)** — Open-source research platform for myoelectric pattern recognition and prosthetic-control experiments.
- **[LibEMG](https://github.com/LibEMG/libemg)** — Python library for real-time and offline EMG pipelines, including data streaming, preprocessing, feature extraction, and model benchmarking.
- **[openhdemg](https://github.com/GiacomoValliPhD/openhdemg)** — Python framework for high-density EMG (HD-EMG) analysis with decomposition workflows and a GUI for common analysis tasks.

### Classical Signal Processing

- Bandpass filtering, notch filtering, and rectification for sEMG preprocessing.
- Root Mean Square (RMS) and Mean Absolute Value (MAV) feature extraction.
- Independent Component Analysis (ICA) and blind source separation for motor unit decomposition from HD-EMG.
- Signal quality checks (electrode placement, motion artifacts, and baseline noise) with structured reporting based on CEDE/SENIAM guidance.

### Gesture & Pose Estimation Pipelines

- Sliding-window classification with CNNs/RNNs for gesture recognition.
- Transformer-based sequence models for continuous kinematic decoding.
- Cross-user generalization via domain adaptation and large-scale pre-training.

## Applications

### Human-Computer Interaction (HCI)

- **Generic neuromotor interface** — [Nature 2025](https://www.nature.com/articles/s41586-025-09255-w): a cross-user, non-invasive wristband-based interface for text entry, cursor control, and gesture input without per-user calibration.
- **Silent / micro-gesture input** for AR/VR, wearables, and smartphones.
- **Hand pose estimation** for avatar control and virtual interaction ([emg2pose](https://github.com/facebookresearch/emg2pose)).

### Prosthetics & Assistive Technology

- Myoelectric control of upper-limb prostheses (foundational use of Ninapro).
- EMG-driven exoskeletons for rehabilitation and augmentation.

### Rehabilitation & Clinical

- Stroke rehabilitation monitoring.
- Assessment of neuromuscular disorders (Parkinson's, muscular dystrophy, ALS).
- Post-surgical recovery (e.g., post-TKA knee rehabilitation).

### Biometrics & Security

- EMG-based user authentication.
- Side-channel analysis (e.g., keylogging via forearm EMG).

### Sports & Biomechanics

- Muscle-activation analysis during gait, running, and cycling.
- Fatigue monitoring and performance optimization.

## Hardware

### Consumer / Emerging Wearables

- **[Meta EMG Wristband](https://www.meta.com/emerging-tech/emg-wearable-technology/)** — Meta's surface-EMG wristband for non-invasive neural input, targeting AR glasses and general HCI. Detects micro-gestures and intended movements from forearm muscle activity.
- **[Mudra Band](https://mudra-band.com/pages/howitworks)** — Consumer neural-input wristband using surface neural signals for touch-free control of Apple Watch, Vision Pro, and other devices via subtle finger gestures.

### Research-Grade sEMG Systems

- **Delsys Trigno** — Wireless sEMG sensors widely used in biomechanics research.
- **Noraxon Ultium** — Clinical and research sEMG with integrated IMU.
- **OT Bioelettronica Quattrocento / Sessantaquattro** — High-density EMG for motor unit decomposition.
- **Myo Armband** (Thalmic Labs, discontinued) — Historically foundational 8-channel consumer sEMG; many research datasets were collected with it.
- **BITalino / OpenBCI Cyton** — Open-source, low-cost EMG acquisition platforms.

### Intramuscular & Implantable

- Fine-wire and needle EMG systems (Natus, Cadwell) for clinical neurology.
- Emerging implantable systems for long-term myoelectric prosthesis control.
